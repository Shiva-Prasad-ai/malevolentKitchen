Malevolent Kitchen Compiler Documentation Sections 1 – 3: Architecture & Objectives

1. Introduction

This project is a browser-based live code compiler and interactive playground designed for modern web development and algorithmic testing. In traditional web environments, compiling and previewing code typically requires heavy IDE installations, local HTTP server configurations, or cloud build pipelines.

The compiler resolves this challenge by providing a lightweight, client-side execution sandbox. The user writes HTML, CSS, and JavaScript in three dedicated editor tabs (or a unified code view) and clicks Run to see the rendered result in an isolated output pane. Because JavaScript executes directly within the client browser, the tool dynamically combines the three parts into a single unified virtual document rendered via an <iframe>. A real-time console panel intercepts and displays console.log() statements, warnings, and error messages sent back from the child frame using the HTML5 postMessage protocol.

2. Objectives

The core educational and functional objectives fulfilled by this project are:

  • Dedicated Language Editors: Provide separate, ergonomic code editors for HTML, CSS, and JavaScript.
  • Live Sandboxed Code Output: Combine markup, styles, and logic on-the-fly to show instantaneous visual results in an isolated container.
  • Integrated Clipboard Operations: Support cut, copy, and paste commands through toolbar action buttons and universal keyboard shortcuts (Ctrl + X, Ctrl + C, Ctrl + V).
  • Console Output & Debugging: Stream console.log() output and runtime error exceptions into a dedicated UI console panel so JavaScript logic can be tested interactively.
  • Case Study Verification: Solve and verify two comprehensive laboratory case studies by executing JavaScript programs directly within the compiler.

3. Technologies Used

HTML5 Page Structure & Sandbox

Defines the UI container layout, toolbar controls, textareas, and the sandboxed <iframe> element that hosts user code in complete process isolation.

CSS3 Modern Studio Interface

Implements responsive Flexbox grid containers, dark-mode design tokens, line-number gutters, glowing telemetry indicators, and resizable layout panels.

JavaScript Core Engine

Coordinates tab switching, clipboard operations, dynamic document bundling, auto-run debounce timers, and DOM manipulation.

postMessage Console Bridge

Injects an instrumentation script into the child iframe that intercepts console calls and securely transmits logs across frame boundaries to the host panel.

4. Features of the Compiler

The compiler integrates a comprehensive suite of features engineered for efficiency and reliability:

  • Three Editor Tabs: Dedicated workspaces for HTML structure, CSS styling, and JavaScript logic, plus support for an all-in-one unified editor mode.
  • Run Button & Debounced Auto-Run: Immediate execution via a prominent RUN button (or Ctrl + Enter), accompanied by automatic re-compilation 500ms after user typing ceases.
  • Clipboard Toolbar & Shortcuts: Dedicated Cut, Copy, and Paste buttons operating on text selections, fully synchronized with standard OS shortcuts (Ctrl+X, Ctrl+C, Ctrl+V).
  • Interactive Console Panel: Dedicated terminal interface capturing console.log(), warnings, error stacks, and execution latency with item counters and clear controls.
  • Multi-Layout Flexibility: Toggle instantaneously between Right Output, Bottom Output, Left Output, and Split-screen layouts.
  • Ultra-Compact Core: The foundational compiler architecture is achieved in only 79 lines of clean code within a single HTML document.

How to Use the Compiler

  1. Select Editor Tab: Choose the HTML, CSS, or JavaScript tab and type or paste your program code.
  2. Use Clipboard Controls: Use Cut, Copy, and Paste (or Ctrl+X, Ctrl+C, Ctrl+V) to move code snippets freely.
  3. Execute Code: Click Run (or press Ctrl + Enter), or simply wait half a second after typing stops to observe the live output.
  4. Inspect Output & Logs: Read console.log() outputs, data types, and runtime errors in the interactive console panel.

7. Case Study 1: Student Profile Card

Concepts: Introduction to JavaScript, Variable Declarations (let, const), Data Types, typeof Operator, DOM Table Generation.
Input Style: Static input.

Problem

Create a JavaScript program to store and display a student's name, register number, semester, percentage, and whether the student has paid the examination fee. Display each value along with its data type in an HTML table and output the records to the console panel.

Requirements

  • Declare suitable variables using let or const.
  • Use at least four different JavaScript data types (String, Number, Boolean, Undefined).
  • Display the values using console.log().
  • Use typeof to display the data type of each variable.

Student Code (HTML + JavaScript)

<h2>Case Study 1: Student Profile Card</h2> <table border="1" cellpadding="6"> <tr><th>Field</th><th>Value</th><th>Data Type</th></tr> </table> <script> let studentName = "Rahul Sharma"; // string const registerNumber = 2105123; // number let semester = 5; // number let percentage = 82.5; // number let feePaid = true; // boolean let backlogs; // undefined function show(label, value) { console.log(label + ": " + value + " (" + typeof value + ")"); document.querySelector("table").innerHTML += "<tr><td>" + label + "</td><td>" + value + "</td><td>" + typeof value + "</td></tr>"; } show("Name", studentName); show("Register No", registerNumber); show("Semester", semester); show("Percentage", percentage); show("Exam Fee Paid", feePaid); show("Backlogs", backlogs); </script>

8. Case Study 2: Simple Shopping Bill

Concepts: Variables, Arithmetic Operators (*, +, /), 5% GST Calculation, Receipt Formatting.
Input Style: Static input.

Problem

A customer purchases three notebooks at Rs. 45 each and two pens at Rs. 20 each. Write a JavaScript program to calculate the subtotal, 5% GST, and the final bill amount. Display the formatted receipt in an HTML <pre> element and log each line to the console panel.

Requirements

  • Store quantity and price separately.
  • Calculate item totals using multiplication.
  • Calculate GST using an arithmetic expression: subtotal * 5 / 100.
  • Display subtotal, GST, and final total in both visual output and console.

Student Code (HTML + JavaScript)

<h2>Case Study 2: Simple Shopping Bill</h2> <pre id="bill"></pre> <script> const notebookQty = 3, notebookPrice = 45; const penQty = 2, penPrice = 20; const notebookTotal = notebookQty * notebookPrice; const penTotal = penQty * penPrice; const subtotal = notebookTotal + penTotal; const gst = subtotal * 5 / 100; const finalTotal = subtotal + gst; const lines = [ "Notebooks : " + notebookQty + " x Rs." + notebookPrice + " = Rs." + notebookTotal, "Pens : " + penQty + " x Rs." + penPrice + " = Rs." + penTotal, "Subtotal = Rs." + subtotal, "GST (5%) = Rs." + gst, "Final Bill Amount = Rs." + finalTotal ]; lines.forEach(l => console.log(l)); document.getElementById("bill").textContent = lines.join("\n"); </script>

9. Advanced Features in Malevolent Kitchen

Building upon the compact 79-line foundation, Malevolent Kitchen Code Studio incorporates production-grade studio capabilities:

Multi-Mode Web Development

Seamlessly switch between Single File mode (all-in-one HTML document) and Split Tabs mode (individual HTML, CSS, and JS tabs) without losing code state.

PHP & Standalone JS Engines

Includes an in-browser standalone JavaScript evaluation engine and a zero-dependency client-side PHP transpiler supporting variables, loops, arrays, and functions.

IntelliSense & Auto-Fill Snippets

Features tag autocompletion and Emmet-style expansion: type ! + Tab for an HTML5 boilerplate, clg + Tab for console.log(), or select from template menus.

Draggable Dividers & Layouts

Interactive draggable splitter allows smooth viewport resizing, while one-click layout presets switch between Right, Left, Bottom, and Split output views.
